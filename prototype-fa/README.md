# پروتوتایپ فارسی علیرضا جابری

نسخهٔ مستقل برای بررسی طراحی؛ فایل‌های سایت اصلی تغییر نکرده‌اند. از مسیر `/prototype-fa/` روی سرور استاتیک اجرا شود. هیچ مرحلهٔ build یا وابستگی جاوااسکریپتی ندارد.

- `index.html`: ساختار فارسی و راست‌چین، نمونه‌کارها و دو مسیر همکاری پروژه‌ای و شغلی.
- `css/style.css`: رنگ‌ها، فونت محلی، چیدمان واکنش‌گرا و حرکت ورودی با پشتیبانی reduced motion.
- `js/main.js`: محتوای فارسی جزئیات پنج پروژه و پنجرهٔ جزئیات.
- `assets`: عکس و تصویرسازی‌های مفهومی پروژه‌ها و نسخهٔ محلی فونت وزیرمتن با مجوز OFL.

اطلاعات پروژه‌ها از محتوای سایت اصلی بازنویسی شده‌اند. تصویرهای پروژه مفهومی هستند و در صفحه با همین عنوان نمایش داده می‌شوند. برای انتشار نهایی، اسکرین‌شات‌های مجاز محصول و داده‌های تأییدشده جایگزین شوند. نقل‌قول مشتری یا آمار نتیجهٔ جدیدی ساخته نشده است. فرایند پیشنهادی همکاری هم پیش از انتشار با شیوهٔ واقعی کار تطبیق داده شود.

این صفحه برای مرحلهٔ طراحی `noindex` دارد. فونت و دارایی‌ها محلی‌اند. برای انتقال به Angular می‌توان بخش‌های صفحه را به کامپوننت‌ها و دادهٔ پروژه‌ها را به یک مدل مستقل تبدیل کرد؛ در این مرحله مهاجرت انجام نشده است.

منبع فونت: https://github.com/rastikerdar/vazirmatn/tree/v33.003 (مجوز در `assets/fonts/OFL.txt`).
